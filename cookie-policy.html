Cookie Policy

Last updated: 14 September 2026

One cookie. Local storage for your picks. Push storage only if you enable alerts. That's everything.

What "cookies and similar technologies" means here

Cookies are small text files a site asks your browser to keep. This site sets exactly one itself. Most preferences instead use local storage (same idea, but never sent to any server), and push alerts add platform storage described below. How each item is cleared is listed with it.

The cookie inventory

swgoh_cookie_notice — remembers that you dismissed the cookie notice. Content: the word dismissed and nothing else — no name, no email, no history, no identifier. Scope: this site, SameSite=Lax. Expiry: six months from dismissal. Legal basis: strictly necessary to remember a UI choice. If you never dismiss the notice, it is never written. Clearing: clear site data, or simply don't dismiss.

Local storage inventory

None of the following leaves your device. All persist until you change the setting, clear site data, or reinstall the browser — there is no server copy.

swgoh-tz — your display-timezone choice. swgoh-tb-choice (plus Light/Dark-side variants) — your guild's Territory Battle picks. swgoh-alerts — whether in-site alerts are switched on. swgoh-alert-cats — which event families you ticked in alert settings. swgoh-alerts-seen — which alerts already fired so they don't repeat; prunes itself after 7 days.

The Alerts panel can export the above (except alert history) to a settings file you keep, and re-import it later — useful precisely because clearing site data otherwise wipes them with no way back.

Push and notification storage

Enabling alerts adds two narrow items. On your device, the Firebase SDK keeps a push token in IndexedDB and your browser holds the notification permission itself. Server-side, one Firestore record (push_subscriptions/{token}) holds that token, your chosen categories and a timestamp so event reminders can reach a closed phone. Switching alerts off deletes that record automatically; dead tokens are cleaned up by the sender. See the Privacy Policy for the full data picture.

Third-party technologies

Google Fonts serves the typefaces, so loading a page requests font files from Google — no cookies are set by this site in the process. Firebase/Google libraries load only after you enable push alerts. GitHub Pages delivers the files over HTTPS. There are no advertising, analytics or social-media trackers anywhere on the site, first- or third-party.

Managing and deleting

Every major browser lets you inspect, block and delete cookies and site data per site (usually under Privacy/Security settings). Blocking the notice cookie is harmless — the schedule works fully, the notice simply reappears each visit. Blocking local storage entirely will break saved preferences (the schedule still renders with defaults). Deleting everything returns the site to a first-visit state; re-import a settings backup to skip re-picking.

Do Not Track

There is nothing here that tracks you across sites, so there is nothing for a Do Not Track signal to switch off — it is respected by default.

Changes

Any new cookie, storage key or push behaviour is documented here first, with a fresh date above.
