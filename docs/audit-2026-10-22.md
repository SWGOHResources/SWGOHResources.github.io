# Website audit and repairs — 22 October 2026

Reviewed SWGOHResources/SWGOHResources.github.io. The source audit started at 43c4a9a368d90efe19fc7275d627d1ce95f0c1a8 and was integrated on 25e8cdd5d5a105833de6c4503fd7114e061cbe02. The separate Node.js/Pillow security remediation, version requirements and all four workflow updates are preserved.

## Application findings repaired

- **Malformed Conquest plans could crash the UI.** Shared and saved fields were used as property keys or converted to numbers before type validation. For example, a JSON object with a null `toString` could throw during conversion; inherited difficulty names such as `constructor` selected prototype properties. Validate bounded primitive fields and feature lists, reject oversized hashes before decoding, normalize storage, and require an own difficulty key.
- **Journey search lost raw aliases after live snapshots rolled forward.** Rotation entries indexed their display text but omitted the configured aliases and unit identifiers. Index those aliases as well. Regression checks cover the feed-backed display and the rotation-only fallback for Terrible Tings, Terrible Things and Darth Jar Jar.
- **Stable module imports could remain obsolete offline-cache entries.** The worker previously revalidated only two named planner modules. Revalidate every unversioned JavaScript URL while keeping visited modules available offline.
- **Partial downloads and failed pages were mishandled by caching.** Range requests could enter a cache rule that cannot store HTTP 206 responses; navigation cached error responses over working pages; background writes were not consistently tied to worker lifetime. Bypass Range requests, store only successful responses, await background cache work with `waitUntil`, and tolerate storage failures. Unvisited offline routes no longer silently show the homepage.
- **The worker deleted caches it did not own and cached arbitrary external origins.** Restrict cleanup to the application's cache prefix and external caching to the Google Fonts origins already used by the site.
- **Model downloads could retain the entire full-pack library in memory.** Bound the fallback full-pack cache to 16 MiB with least-recently-used eviction, trim inactive decoded models when previews change, add bounded request timeouts, and clear a failed catalog promise so later attempts can recover.

Historical interaction tests now use `tests/fixtures/historical-live-events.json` rather than the automatically refreshed production snapshot. The production freshness and asset-integrity checks continue to inspect the real snapshot.

The full run also exposed two test-harness issues: exact-day rounding used separate `Date.now()` calls, and a maintenance CLI's ten-second subprocess budget could expire under parallel asset-test load. Use one fixed instant for rounding and a bounded 30-second CLI budget, with an explicit subprocess-error assertion. The CLI test also passed independently. No assertions or tests were removed or skipped.
